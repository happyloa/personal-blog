## 修改

- 中文 Google Fonts 樣式表先以非阻塞方式載入，內容先使用系統字型。樣式表就緒且瀏覽器完成初次繪製後再套用；保留停用 JavaScript 的 `noscript` 載入方式與連線失敗時的系統字型。
- Mermaid 圖表接近畫面才載入程式並逐張渲染，載入期間保留原始碼。換頁時清理觀察器，已換頁的渲染工作不再建立舊頁圖表；展開原始碼與重複初始化也不會再次轉換它。
- 一般圖表使用 [Mermaid 官方支援的 Dagre 排版](https://mermaid.js.org/config/layouts)，避免下載大型 ELK 程式。流程圖保留文字大小，寬圖表可水平捲動。
- 減少動態效果模式下完整停用圖表 SVG 動畫，修正極短動畫干擾尺寸量測、導致節點間距過大的問題。

## 驗證與報告

格式、Astro 型別檢查、三項依賴安全測試與 48 頁正式建置均通過；套件更新的乾淨安裝成功，npm audit 為 0 漏洞。

真實 Chrome 驗證涵蓋手機首頁、字型完成載入、水平溢出、捲動載入圖表、保留原始碼、重複初始化、手機目錄與 Escape、ClientRouter 換頁、多張圖表、停用 JavaScript、字型連線失敗、延遲字型、減少動態效果及無 IntersectionObserver 的 fallback。另檢視手機與桌機截圖，並確認減少動態效果模式的圖表實際尺寸。

本機 `.lighthouse/` 保留 HTML、JSON、trace、截圖、瀏覽器驗證結果與靜態伺服器腳本，該目錄不納入 Git。分數摘要為 `summary.json`，主要報告為 `final-home.report.html`、`final-article.report.html`、`final-mermaid.report.html`。

中途版本曾出現一次首頁效能 56 分、FCP 10.3 秒的異常量測，原始報告保留為 `after-home-2.json`。調整字型套用時機後，最終版本另量測三次，首頁均為 98 分。[Lighthouse 官方說明](https://developer.chrome.com/docs/lighthouse/performance/performance-scoring)也列出環境、設備與網路造成的分數波動；仍需以多次量測及線上資料追蹤成效。

中文字型總下載量仍受頁面內容與 Google Fonts 分片影響；這次改善的是首次繪製的阻塞時間。接近圖表時仍需下載 Mermaid，複雜圖表也會有額外渲染成本。
